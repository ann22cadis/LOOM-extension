# LOOM

Расширение для SillyTavern: мастерская для карточек персонажей, персон, лорбуков, сюжетов, промптов и пресетов. Модель пишет черновик, вы оцениваете каждый абзац сердечками и комментариями, модель переписывает только то, что не понравилось.

Статус: **публичная бета (0.1.0)**. Возможны баги. Перед правкой важных карточек и лорбуков делайте копии (LOOM делает их сам при импорте, но лишняя копия не помешает).

## Установка

Расширения → Установить расширение → вставьте ссылку:

```
https://github.com/ann22cadis/LOOM-extension
```

Автообновление выключено: обновляйте вручную через менеджер расширений Таверны.

## Что умеет

| Режим | Что делает |
|---|---|
| Персонаж | Карточка по пунктам формата. Экспорт в Таверну, PNG или JSON, перевод на английский, варианты первого сообщения |
| Персона | Описание персоны, экспорт в Таверну или JSON |
| Лорбук | План записей, текст каждой записи, ключи с морфологией (регулярные выражения для склоняемых слов), экспорт в лорбук Таверны |
| Сюжет | Цепочка шагов и этапов. Привязывается к чату и следит за ходом ролевой |
| Промпт | Короткие ситуативные инструкции для модели, которая ведёт сцену |
| Пресет | Блоки пресета Chat Completion, экспорт в пресеты Таверны. Есть «Анализ пресета» |

Общее для всех режимов:

- оценка абзаца от 1 до 10 и комментарий; при «Переписать с оценками» абзацы с оценкой от 8 и выше (порог меняется в настройках) остаются как есть;
- история версий с откатом;
- референсы-картинки для моделей с поддержкой изображений;
- импорт из Таверны (персонаж, лорбук, персона, пресет) и из файла (PNG-карта, JSON);
- форматы: наборы пунктов можно менять, сохранять и передавать файлом;
- темы оформления, мобильная раскладка.

Необязательная функция, **выключена по умолчанию**: «Папки». Долгое нажатие на папки Таверны открывает раскладку персонажей по папкам и меняет вид папок. Использует штатные теги Таверны.

## Куда уходят данные

Расширение не обращается ни к каким адресам вне Таверны: ни аналитики, ни CDN, ни сторонних API. Все запросы идут на сервер вашей Таверны.

За пределы вашего сервера данные уходят **только** одним способом: запрос к языковой модели. Его отправляет сама Таверна провайдеру из выбранного в LOOM профиля подключения (или главного API Таверны). LOOM не читает и не хранит ваши API-ключи: он называет профиль, а ключ подставляет сервер Таверны.

### Что попадает в запрос к модели

| Что | Когда |
|---|---|
| Текст черновика, оценки, комментарии, ваши заметки и задумка | при любой генерации и переписывании |
| Записи лорбука и блоки пресета (для согласованности) | при работе с лорбуком или пресетом |
| Карточки персонажей и персон из LOOM, которые вы привязали к лорбуку или сюжету | при генерации этого лорбука или сюжета |
| Картинки-референсы | только если вы их прикрепили и выбран профиль подключения; главный API Таверны картинки не принимает |
| Описание, характер и сценарий персонажа чата и описание персоны (по 1500 символов) | при создании сюжета |
| Короткая инструкция с текущим шагом сюжета и раз в N ответов просьба дописать метку `<plot>`: добавляются в **обычный запрос чата**, отдельного запроса нет | пока сюжет привязан к чату (режим `inline`, по умолчанию) |
| Последние до 6 сообщений чата, по 1500 символов | только в режиме сюжета `request`: отдельная проверка раз в N ответов |

Провайдер модели видит всё перечисленное. Если не хотите отправлять чат, оставьте режим сюжета `inline` или `manual`.

### Запросы на сервер Таверны (не наружу)

| Запрос | Зачем |
|---|---|
| `backends/chat-completions/generate` | запасной путь отправки модели, если профили подключения недоступны |
| `characters/import`, `characters/merge-attributes`, `characters/edit-avatar`, `characters/duplicate` | экспорт, обновление и резервная копия персонажа |
| `worldinfo/get` и сохранение лорбука через Таверну | экспорт лорбука, проверка, что записи сохранились, резервная копия при импорте |
| сохранение пресета через Таверну | экспорт пресета |
| `avatars/upload` | аватар персоны |
| сохранение настроек Таверны | настройки и черновики LOOM |
| чтение миниатюр, аватаров, `/img/user-default.png`, собственного `style.css` | оформление |

## Что LOOM пишет в данные Таверны

LOOM меняет данные Таверны только когда вы нажали соответствующую кнопку экспорта, импорта или привязки:

- **Персонаж**: «Обновить в Таверне» правит текстовые поля существующего файла. При импорте из Таверны заранее делается резервная копия.
- **Лорбук**: экспорт дополняет существующий лорбук, а не затирает его. Записи обновляются на месте только в том лорбуке, откуда пришли или куда уже писал этот черновик; в другой лорбук идут новые записи. При импорте делается резервная копия.
- **Пресет**: то же правило по блокам.
- **Персона**: загружается аватар, обновляется описание.
- **Сюжет**: при привязке к чату состояние хранится в метаданных этого чата (`loom_plot`). Метка `<plot>` вырезается из ответов модели, после чего чат сохраняется. В промпт чата добавляется короткое напоминание о текущем шаге.
- **Папки** (если включены): меняются теги и привязки тегов Таверны.

## Где хранятся данные LOOM

- Черновики и настройки: `settings.json` Таверны, раздел `extension_settings.LOOM`. API-ключей там нет.
- Картинки-референсы, аватары карточек и папок: IndexedDB браузера. Они **не синхронизируются** между устройствами.
- Положение групп в списке: `localStorage` браузера.

Другие расширения Таверны могут читать `settings.json`. Если в черновиках есть то, что нельзя показывать, помните об этом.

## Безопасность

- Весь пользовательский текст (карточки, ответы модели, имена файлов, импортированные данные) показывается с экранированием HTML; расширение не исполняет полученный текст как код.
- Картинки пересобираются через canvas, то есть остаются обычными растровыми.
- Файлы при импорте разбираются в браузере; формат пресетов форматов проверяется и отбрасывает лишние поля.
- Нет `eval`, нет внешних скриптов, зависимостей и сборки: в репозитории только исходники.
- Известное ограничение: регулярные выражения для ключей лорбука, которые предложила модель, проверяются только на корректность. Очень «тяжёлое» выражение может подвесить вкладку.

Нашли уязвимость или утечку? Откройте issue в репозитории и не прикладывайте свои карточки и ключи.

## Примечания

- Лорбуки и ключи рассчитаны прежде всего на русский язык, но язык ключей и результата выбирается в настройках.
- На iPhone (TauriTavern) панель и окна учитывают вырез и статус-бар.
- Лицензия пока не указана.
